ГЕНДАЛЬФ

Письма из сканов — в Word. Автоматически.
PDF · OCR rus+eng · таблицы · реестр «СКАНЫ»
Ведите курсором: Око-палантир притягивает письма, сканирует их и раскладывает по каналам справа. Прокрутите вниз — параллакс.

ᚠО проекте

Гендальф — веб-приложение на Django для локальной сети. Пользователь загружает скан письма (PDF), система превращает его в Word-документ: текстовые PDF разбираются напрямую (PyMuPDF), сканы распознаются OCR Tesseract (русский + английский). Скан и документ показываются рядом, документ можно править и сохранить как .docx. Все сохранения попадают в общий реестр «СКАНЫ» с фильтрами и поиском.

1 · ТЕКСТ-СЛОЙPyMuPDF извлекает абзацы, жирный/курсив, размеры шрифтов (→ заголовки), выравнивание, картинки.
2 · СКАН · OCRРендер 300 dpi → оттенки серого + автоконтраст → Tesseract (rus+eng) → абзацы и заголовки.
3 · ТАБЛИЦАЛинии сетки находятся на скане, слова раскладываются по ячейкам; объединённые ячейки (colspan/rowspan) сохраняются.

ᚱВозможности

  • Авторизация, администратор добавляет пользователей.
  • Слева PDF-скан, справа редактируемый Word-документ (жирный/курсив/подчёркивание, выравнивание, списки, заголовки).
  • Кнопка «Сохранить WORD файл» — файл записывается на компьютере пользователя, запись попадает в «СКАНЫ».
  • «СКАНЫ»: таблица с фильтром по каждому столбцу и поиском слова по всем столбцам сразу.
