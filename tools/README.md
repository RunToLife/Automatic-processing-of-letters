# Визуальные ассеты «Гендальфа»

Все картинки в `assets/` — **чистый SVG без JavaScript, внешних файлов и шрифтов**; их собирает генератор
из этой папки. Руками SVG править не нужно.

| Файл | Что это | Размер |
|---|---|---|
| `assets/banner.svg` | главный баннер: хаос писем слева → Око-палантир → порядок справа, маяки на горах, печать | 1280×400 |
| `assets/divider.svg` | разделитель секций: бегущие письма и руны вдоль неоновой линии | 1280×44 |
| `assets/footer.svg` | футер: пульсирующая печать и цепочка маяков | 1280×120 |
| `assets/typing.svg` | «печатающийся» заголовок со слоганами | 860×48 |
| `assets/stack.svg` | неоновые бейджи реального стека (`requirements.txt`) | 860×90 |
| `assets/*-light.svg` | варианты для светлой темы GitHub (подключаются через `<picture>`) | — |
| `letters/static/letters/img/*.svg` | ассеты самого веб-сервиса: печать-логотип, фавикон, фон входа (башня и Око), фон приложения, конверт-заглушка, сканирующее Око | — |

## Оформление самого сервиса

Интерфейс «Гендальфа» оформлен в том же стиле (киберпанк × Властелин колец):

* `letters/static/letters/style.css` — вся тема приложения (CSS-переменные `--gold`, `--cyan`, `--mag`, `--red`, `--bg`, `--mut` в начале файла);
* `letters/static/letters/admin.css` + `templates/admin/base_site.html` — та же тема для раздела «Пользователи» (`/admin/`);
* `templates/base.html`, `templates/registration/login.html` — логотип-печать и фавикон;
* SVG-фоны и иконки собирает `tools/visuals/service.py` (`python3 tools/build_visuals.py service`).

Документ в редакторе («бумага») намеренно остаётся светлым: это то, что уйдёт в Word. Анимации отключаются
при `prefers-reduced-motion`; внешних шрифтов и картинок нет — сервис работает офлайн в закрытой сети.

## Пересборка

```bash
python3 tools/build_visuals.py            # всё
python3 tools/build_visuals.py banner     # только баннер (также: divider footer typing stack service)
```

Нужен только Python 3 (стандартная библиотека).

## Как поменять цвета

* **Палитра** — словарь `THEMES` в `tools/visuals/core.py` (`dark` и `light`): `bg`, `gold`, `cyan`, `magenta`,
  `red`, `muted`. Они попадают в CSS-переменные `:root{--bg:…;--gold:…}` в самом начале `<style>` каждого SVG,
  так что цвет можно быстро поправить и прямо в готовом файле.
* Остальные параметры темы: `blend` (режим наложения свечения), `grain_op` (зерно), `scan_op` (scanlines),
  `vig_op` (виньетка), `haze` (сила тумана).

## Как поменять тексты

CSS-переменные не умеют хранить текст внутри SVG, поэтому тексты вынесены в блоки-константы:

* баннер — `TEXTS` в `tools/visuals/banner.py` (название, подпись, слоган, метки каналов и голограмм);
* футер, typing, бейджи — `FOOTER_*`, `TYPING`, `STACK` в `tools/visuals/small.py`.

Ширина текстов зафиксирована через `textLength`, поэтому вёрстка не «плывёт» на разных системах (шрифты —
системный моноспейс-стек, внешних шрифтов нет).

## Тайминги баннера

* бесшовный цикл `D = 12` с (`banner.py`), в нём 8 «писем-героев» (`NL`), у каждого свой сдвиг `begin = -i·D/NL`;
* интро ≈ 3 с: слои «включаются» мерцающей вывеской (`intro()`), затем цикл идёт бесконечно;
* glitch-вспышка раз в 7 с (`GL`), маяки зажигаются цепочкой раз за цикл;
* `prefers-reduced-motion`: показывается статичный кадр (`#still`), анимация (`#live`) скрывается.

## Превью локально

```bash
python3 -m http.server 8000      # из корня репозитория
# открыть http://localhost:8000/assets/banner.svg  (или docs/index.html — лендинг)
```

SVG можно просто открыть в браузере двойным щелчком. Для PNG-кадров удобно Playwright/Chromium:
`svg.pauseAnimations(); svg.setCurrentTime(5)` и скриншот.

## Проверка перед коммитом

```bash
xmllint --noout assets/*.svg
grep -c "<script" assets/*.svg          # везде 0
ls -l assets/                           # каждый файл < 500 КБ
```
